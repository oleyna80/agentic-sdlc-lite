# Project Changes

Store durable documents here only when a task needs them, for example:

```text
docs/changes/login-rate-limit/
├── intent.md
├── spec.md
├── plan.md
└── closeout.md
```

Copy only the relevant templates from `docs/templates/`. Routine single-file changes need no task directory if the PR contains sufficient context. No directory or Markdown status grants authority.
